# MongoDB

MongoDB is a source-available, document-oriented database that stores data in flexible, JSON-like documents, making it easy to model data of varying structures.

## Get started

1. Run `docker-compose up` in the mongodb folder
1. Use mongosh for managing the database: `docker exec -it mongodb mongosh -u mongouser -p mongopwd`
